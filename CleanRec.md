# CleanRec
Версия 1.0

## 1. Общие положения
**CleanRec** — лёгкое и быстрое мультиплатформенное приложение для записи видео с экрана и звука на мобильных устройствах.
- **Модель распространения:** Полностью бесплатно, без рекламы, встроенных покупок, водяных знаков и сбора пользовательских данных.
- **Целевая аудитория:** Владельцы смартфонов (включая бюджетные модели без встроенной записи экрана), геймеры, авторы туториалов и обычные пользователи.
- **Платформы:** Android (основная цель — публикация в Google Play / RuStore), архитектурный задел под iOS.
- **Стек технологий:** Kotlin Multiplatform (KMP) + Compose Multiplatform.
- **Локализация:** Встроенная поддержка 3 языков (**English**, **Русский**, **简体中文**) с автоматическим определением языка системы и мгновенным переключением в один тап.

## 2. Дизайн и визуальный стиль
Интерфейс выполнен в тёмном технологичном минимализме с единой дизайн-системой (`Theme.kt`):
- **Основной фон (`BgDark`):** `#0B0F14`
- **Поверхности / карточки (`SurfaceDark`):** `#131922` со скруглением `16dp`–`20dp`.
- **Главный акцент (`AccentCyan`):** неоново-синий / циан `#00E5FF` (кнопка «Старт», активная вкладка, переключатель языка, бейджи).
- **Дополнительный акцент (`AccentSecondary`):** индиго `#6C63FF`.
- **Акцент записи и удаления (`AccentRed`):** `#FF4D6D` (кнопка «Стоп», статус активной записи, кнопка удаления).
- **Текст:** основной `#E6EDF3`, второстепенный `#9AA4B2`.

## 3. Основной функционал (Реализовано в Версии 1.0)

### 3.1. Управление записью и онбординг
- **Встроенное обучение (Мини-гайд):** Понятная инструкция из 3 шагов при первом запуске приложения и вызов по кнопке **`?`** в верхней панели.
- **Главный экран (`RecorderScreen`):** Крупная круглая кнопка «Старт / Стоп» с живым таймером записи и адаптацией под портретную и альбомную ориентацию экрана.
- **Обратный отсчёт 5 секунд:** После подтверждения захвата приложение сворачивается на рабочий стол и даёт 5 секунд (с отображением обратного отсчёта в шторке), чтобы пользователь успел открыть нужную игру или программу до начала записи.
- **Управление из шторки (`ScreenRecordService`):** Постоянное системное уведомление с живым секундомером и кнопкой **«Стоп»** для завершения записи без возврата в приложение.

### 3.2. Звук и параметры видео
Лаконичная карточка настроек перед началом записи:
- **Звук с микрофона:** Включение / отключение записи голоса и внешних звуков через микрофон (AAC, 128 kbps, 44.1 kHz).
- **Разрешение видео:** Выбор между **720p (HD)** и **1080p (Full HD)** с сохранением пропорций экрана (H.264, 30 FPS, битрейт 6 Мбит/с).

### 3.3. Встроенная галерея и видеоредактор (`GalleryScreen` + `VideoTrimEditor`)
Отдельная вкладка «Мои видео» со списком всех записей из системной папки `Movies/CleanRec` (через `MediaStore`):
- **Карточка ролика:** Отображение даты и времени записи, длительности, размера файла и бейджа **`Обрезано`** для смонтированных видео.
- **Встроенный видеорезак (Тример):** Полноэкранный редактор на базе нативных `MediaExtractor` и `MediaMuxer` (мгновенная обрезка без перекодирования и потери качества) с живым предпросмотром кадров, двойным ползунком «Начало / Конец» и кнопками точной подгонки **`±1с`**.
- **Быстрые действия:** **Смотреть** (во внешнем плеере), **Обрезать**, **Поделиться**, **Удалить**.

## 4. Архитектура проекта (KMP)
Проект разделён на общую логику и нативные платформенные модули:

| Модуль / Файл | Назначение |
| :--- | :--- |
| `commonMain` | Пользовательский интерфейс на Compose Multiplatform (`MainScreen`, `RecorderScreen`, `GalleryScreen`, `HelpDialog`), дизайн-система (`Theme.kt`), парсер мультиязычных ресурсов (`AppResources.kt`) и `expect`-интерфейсы. |
| `androidMain` | Нативная реализация (`actual`): захват экрана через `MediaProjection`, кодирование через `MediaRecorder`, фоновый сервис `ScreenRecordService`, видеоплеер редактора `VideoTrimEditor.android.kt`, быстрый тример `VideoTrimmer.android.kt` (`MediaExtractor` + `MediaMuxer`), работа с `MediaStore` и `SharedPreferences`. |
| `iosMain` | Архитектурный задел (`actual`-заглушки для будущей реализации на базе `ReplayKit` и `NSUserDefaults`). |

## 5. Требования для публикации в Google Play
- **Безопасность данных (Data Safety):** Приложение работает полностью офлайн, не требует регистрации и не собирает/не отправляет никакие пользовательские данные.
- **Политика конфиденциальности (Privacy Policy):** Статичная веб-страница с описанием отсутствия сбора данных.
- **Запрос разрешений:** Разрешения (`RECORD_AUDIO`, `POST_NOTIFICATIONS`, системный диалог `MediaProjection`) запрашиваются строго по факту нажатия кнопки «Старт», без лишних разрешений поверх других окон.
- **Актуальные API:** Корректное объявление типов фонового сервиса (`foregroundServiceType="mediaProjection|microphone"`).

## 6. План развития (После релиза 1.0)
Функции для будущих обновлений (v1.1+):
- Запись внутреннего системного звука устройства (AudioPlaybackCapture API на Android 10+) и комбинированный режим «Микрофон + Системный звук».
- Расширенные настройки видео: выбор частоты кадров (60 FPS) и битрейта.
- Превью-миниатюры (thumbnails) в карточках галереи и ручное переименование файлов.
- Реализация нативного захвата экрана на iOS через `ReplayKit`.
